## Description (max 16,000 chars)

```
OnboardAI turns any web page into an interactive walkthrough. Hold ⌘ (or Ctrl on Windows) and the page dims with a spotlight following your cursor. Click any button, link, or UI element, and a small popup appears anchored to that element with a streamed AI explanation: what it is, what it does, and why it matters. Ask follow-up questions in the same popup to go deeper.

FREE TO USE — NO API KEY NEEDED
Shoofly provides the Claude connection. No signup, no API key, no credit card. Just install and start clicking.

PRIVACY-FIRST DESIGN
OnboardAI is built so it is provably unable to read what you type:
• Form values and passwords are never read — field values are excluded from context
• Rich-text editors and contenteditable regions are skipped entirely
• URL query strings and tokens (session IDs, OAuth codes) are never sent
• Email addresses are scrubbed from page titles

CLAUDE DOESN'T TRAIN ON YOUR DATA
We use Anthropic's commercial API with a zero-retention policy. Your questions and the pages you click are not stored or used to improve AI models.

HOW IT WORKS
1. Hold ⌘ (Ctrl on Windows) — the page dims and a spotlight follows your cursor
2. Click any element — OnboardAI extracts the element's label, nearby text, and URL path
3. A streamed answer appears in a popup anchored to what you clicked
4. Ask follow-ups in the same popup

NO SHOOFLY DATABASE
There is no analytics, no telemetry, no user accounts. Requests go through a minimal proxy that adds the API key server-side and logs nothing. Your conversation context lives in memory and is gone when you close the popup.

PERFECT FOR
• Learning new SaaS tools without hunting for docs
• Onboarding teammates with instant explanations
• Understanding complex dashboards and admin panels
• Exploring unfamiliar codebases (GitHub, GitLab, etc.)

Read the full privacy policy: https://onboardai-shoofly.netlify.app/#privacy
```

This extension explains any UI element the user ⌘-clicks by sending a sanitized snapshot of that element (label, nearby text, page title, and URL path) through a proxy to Anthropic's API to generate a streamed explanation shown in a popup anchored to the element.
