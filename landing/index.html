Install

Up and running in 60 seconds

One step at a time — with screenshots of exactly what you'll see.

Step 1 of 6 — Download

Download OnboardAI

Grab the extension — it's a small zip file.

⬇ Download onboardai.zip

Heads up: Chrome may show a bubble asking to keep the file. Click Keep — it lands in your Downloads folder.

Unzip it

Open your Downloads folder and double-click onboardai.zip. macOS creates a folder called onboardai right next to it.

Open your Downloads folder, right-click onboardai.zip → Extract All… → Extract.

Windows note: Extracting creates a folder inside a folder — onboardai\onboardai. In step 5, pick the inner one (the one with manifest.json).

Open Chrome's extensions page

Copy this address and paste it into Chrome's address bar, then press Enter.

chrome://extensions

Browsers don't allow clicking chrome:// links — pasting it yourself works every time.

Turn on Developer mode

Find the Developer mode switch in the top-right corner and flip it on.

The toggle is at the top-right, next to "Developer mode".

Keep it on. Turning it off disables the extension — flip it back and click the reload arrow to restore.

Click "Load unpacked"

A toolbar appeared at the top. Click Load unpacked, then pick the onboardai folder you unzipped.

📁 Downloads
📂 onboardai ← pick this folder (the inner one)

You'll see this card when it works:

Seeing "Manifest file is missing"?
You picked the wrong folder — usually the outer one (the onboardai\onboardai double-folder). Click Load unpacked again and choose the folder that contains manifest.json.

Pin it (optional)

Click the puzzle-piece icon next to the address bar, then the pin next to OnboardAI. Settings will be one click away.

address bar · 🧩 ← click
✦ OnboardAI by Shoofly 📌 ← pin

Skippable — the extension works either way.

🎉 You're all set

Try it now: hold ⌘Ctrl and click anything on this page. A spotlight will follow your cursor, and clicking opens your first answer.

If nothing happens, reload this page once (extensions attach to pages opened after install).

Done with onboarding? Click the OnboardAI icon → "Remove OnboardAI" to uninstall cleanly.

Privacy & Security

Built for pages where you type sensitive things

Sees (only when you click)

  • The clicked element's label
  • Nearby text and page title
  • The URL path only (no tokens)

Never sees

  • Form values or passwords
  • What you type in editors
  • URL tokens (session IDs, OAuth)
  • Anything until you click

No account, no signup, no API key. Shoofly provides the Claude connection — you just use it.

Claude doesn't train on your data. We use Anthropic's commercial API with a zero-retention policy — nothing you click is stored or used to improve AI models.

No Shoofly database. We don't store your questions, your pages, or anything about you. The only data that leaves your browser goes to Anthropic's API and back.

FAQ

Questions

Is it really free?
Yes. Shoofly covers the AI costs. No signup, no trial, no credit card.
What happens to normal ⌘-click?
While OnboardAI is on, ⌘-click asks about elements instead of opening links in new tabs. There's a toggle in settings to switch back instantly.
Does it work on internal/company tools?
Yes — any page Chrome can open, including intranets and admin panels.
Which browsers?
Chrome and Chromium-based browsers (Edge, Brave, Arc). On Windows/Linux, hold Ctrl instead of ⌘.
Is my data stored anywhere?
No. Questions go to Anthropic's zero-retention API and come straight back. Nothing is logged by Shoofly or used for training.
